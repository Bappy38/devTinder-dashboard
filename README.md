# DevTinder Frontend

DevTinder is a platform where developers can discover and connect with like-minded peers. This is the frontend part of the project, built using Vite + React and Redux for state management.

## 🚀 Features

- Browse and interact with developer profiles
- Send connection requests
- Chat in real-time with connections
- Modern responsive UI
- Redux-powered global state
- Protected routes based on login status

## 🛠 Tech Stack

- **Vite** – Fast frontend tooling
- **React** – UI development
- **Redux Toolkit** – State management
- **Axios** – API requests
- **Tailwind CSS** – Styling
- **React Router** – Navigation

## 📦 Installation

```bash
git clone https://github.com/your-username/devtinder-frontend.git
cd devtinder-frontend
npm install
```

## Environment Variable

```
VITE_API_BASE_URL=http://localhost:3000
```
