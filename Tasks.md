# TASKS

- Create a `Vite + React` application
- Remove unnecessary code from project template
- Install `TailwindCSS` in your Vite project
- Install `daisyUI` as a `TailwindCSS` plugin
- Install `react-router-dom`
- Create routes using BrowserRouter (Declarative Mode)
- Create Login Page
- Install axios
- Install `cors` and use middleware with `origin` and `credentials` configuration in backend
- Whenever you're making API call through axios, pass `{withCredentials: true}`
